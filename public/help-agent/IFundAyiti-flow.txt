Page Name:
IFundAyiti

Page Goal:
Build a dedicated IFundAyiti page within the website to help individuals living in Haiti apply for micro grants. This is NOT a crowdfunding platform where donors donate directly to applicants. Instead, all donations go into a single IFundAyiti Program Fund. Applicants submit grant applications, the IFundAyiti team reviews and vets them, selects the Top 5 finalists, and finally chooses one winner for each application period. The organization manually transfers the grant to the selected winner outside the platform.

Unlike the main website, IFundAyiti does not require applicants to create user accounts. Instead, after submitting an application, the system generates a unique Application Tracking ID that applicants can use to check the status of their application at any time.

====================================================
IMPORTANT BUSINESS RULES
====================================================

- Donations always go to the IFundAyiti Program Fund.
- Donations are never made directly to applicants.
- Applicants do not create user accounts.
- Every application receives a unique Tracking ID after submission.
- Applicants use the Tracking ID (and Date of Birth for verification) to check their application status.
- Maximum grant request is $1000.
- Only admins can edit applications after submission.
- Only admins can approve or reject applications.
- Only approved applicants become publicly visible.
- Top 5 finalists are selected manually by the IFundAyiti team.
- One winner is selected for each application period.
- Grant payments are transferred manually outside the platform.
- Missing required documents may result in application rejection.
- All uploaded files are stored in a single documents array with metadata indicating document type.
- All form validation should be implemented using Zod on the frontend and validated again on the backend.
